# Run 1 data extracts

CSV extracts of the account's databases, read-only, for the run record `../../README.md` (docs/runs/run-1). Committed, scrubbed (account number, Telegram ids, prompts and credentials are not in them). The complete databases are Tier 2, on the operator's machine only (`data/runs/run-1/db/`, see `../README.md`; the record's own "Evidence" section is `../../README.md`).

**How they were made.** On 2026-11-19 at 05:08:57Z a consistent copy of each database was taken with `sqlite3 <src> ".backup <dest>"` (Tier 2). The extracts were read from those copies with `sqlite3`/Python `mode=ro` (`file:...?mode=ro`; the older backups, which are WAL-mode files with no sidecars, with `mode=ro&immutable=1`). The three pruned tables (`portfolio_snapshots`, `risk_verdicts`, and the history behind them) were also read from ten older consistent copies of `income_system.db` that the machine had kept (`data/backups/` daily copies from 2026-11-10 to 2026-11-18, and the three pre-fix backups of 2026-09-30, 2026-10-01 and 2026-10-06), unioned by row id; they are in Tier 2 under `db/older-backups/`, because the daily copies rotate away.  no live database was opened for writing and no switch or `system_settings` row was touched. The queries below are the SQL (or the Python reduction) that produced each file; run them against `data/income_system.db`, `data/spreads.db` or `data/value.db` for the same shape, bearing in mind the live files keep changing (and several tables are pruned over time, lesson N4: the row counts below are those at capture).

**Tags** follow the record: **[V]** verified from the database; **[M]** a model or approximation. The only [M] column in this folder is `nlv_usd` on the SGD-era rows of `nlv_journal.csv` and `nlv_portfolio_snapshots.csv` (`tag` = M); everything else is stored data.

**Conventions.** Times are as stored: the databases hold UTC unless a column says otherwise; `broker_executions.trade_time` for rows the live feed booked before the 2026-11-18 restart reads 8 hours behind UTC (record header). `claude_usage_calls.csv` times are the log's local clock (UTC+8).
